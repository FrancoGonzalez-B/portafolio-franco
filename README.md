# Portafolio de Franco González

Página personal para presentarme, mostrar trabajos del semestre y compartir mis datos de contacto.

## Tecnologías

- HTML5
- CSS externo
- Sin JavaScript ni dependencias


## Cómo abrirlo

Abre esta carpeta en Visual Studio Code y luego abre `index.html` con Live Server o en un navegador.

## Decisiones y accesibilidad

La página está pensada para que docentes y reclutadores encuentren primero mi presentación, luego mis trabajos y finalmente mi contacto. El HTML usa encabezados y secciones semánticas. El CSS se adapta a distintos tamaños en 600, 900 y 1200 px. La imagen tiene texto alternativo; el menú se puede recorrer con teclado y los campos del formulario tienen etiquetas.

Los colores se cambian al inicio de `css/styles.css`, dentro de `:root`.
